# 04. Враги

Враги делятся на четыре фракции и три «веса»: Lesser (рядовые), Greater (элита) и Supreme (боссы).

## Husks (Оболочки)
Души проклятых людей в телах из плоти. Это «пушечное мясо» Ада.
| Враг | Суть |
|---|---|
| Filth | Хилый, но многочисленный: бежит и кусает |
| Stray | Стреляет энергошарами издалека |
| Schism | Стреляет связанными снарядами по шаблонам |
| Soldier | Залпы снарядов, пинает вблизи |
| Stalker | Посыпает других врагов песком, после чего с них нельзя получать кровь |
| Ferryman | Перевозчик (Харон-подобный): молнии и комбо веслом |
| **Mirror Reaper** | Босс-Husk из Fraud: самонаводящиеся руки, газ, взмахи |
| **Corpse of King Minos** | Гигантский труп царя Миноса (босс 2-4) |
| **Insurrectionist** | Гигант-повстанец, бьёт мёртвым Malicious Face как кистенём |

## Machines (Машины)
Боевые роботы, как и сам V1. Тоже ищут кровь.
| Враг | Суть |
|---|---|
| Swordsmachine | Робот с мечом. При половине HP бросает дробовик (его можно подобрать) |
| Drone | Летает и стреляет, при смерти таранит |
| Streetcleaner | Огнемёт, слабое место — баллон на спине |
| Mindflayer | Телепортируется, стреляет лучами и самонаводящимися снарядами |
| Sentry | Заряжает точный хитскан-луч |
| Gutterman | Пулемёт и щит, со временем целится всё точнее (Слой 7) |
| Guttertank | Ракеты, мины, удар вблизи (Слой 7) |
| **V2** | «Брат» V1: копирует движение и оружие игрока |
| **1000-THR «Earthmover»** | Гигантская военная машина, по ней надо карабкаться к «мозгу» (7-4) |

## Demons (Демоны)
Существа, созданные Адом.
| Враг | Суть |
|---|---|
| Malicious Face | Летающая голова: взрывной луч, иммунитет к взрывам |
| Cerberus | Статуя-страж: бросает «яблоко», рывок, топот |
| Hideous Mass | Бронированная масса: миномёт и гарпун |
| Idol | Делает другого врага неуязвимым, пока жив |
| Mannequin | Быстро ползает по стенам |
| Deathcatcher | Поднимает убитых врагов как марионеток (Слой 8) |
| **Minotaur** | Босс Слоя 7: молот, кислота, таран |
| **Leviathan** | Морской гигант (5-4) |
| **Geryon** | Летающий босс-«bullet hell» (8-4) |

## Angels (Ангелы)
Слуги Рая.
| Враг | Суть |
|---|---|
| Virtue | Вызывает столбы света |
| Providence | Магентовые лучи, после смерти оставляет точку для крюка с лечением (Слой 8) |
| Power | Элитный ангел с конструктами света, уязвим после парирования (Слой 8) |
| **Gabriel** | Архангел, главный антагонист Актов I–II (3-2, 6-2) |

## Prime Souls (Первичные души)
Освобождённые души великих грешников. Это самые сложные боссы игры.
- **Minos Prime** (P-1): освобождённая душа царя Миноса. Быстрые удары и пинки.
- **Sisyphus Prime** (P-2): освобождённая душа царя Сизифа. Телепорты и взрывы.

Перед каждым из них идёт «тюрьма»: **Flesh Prison** и **Flesh Panopticon**.

## Прочее и пасхалки
- **Something Wicked** — неубиваемая сущность из 0-S, убивает касанием.
- **Cancerous Rodent / Very Cancerous Rodent** — мем-крыса.
- **Mysterious Druid Knight (& Owl)** — босс-пасхалка.
- **Big Johninator** — пасхальный робот на ИИ V2.
- **Puppet** — марионетка, поднятая Deathcatcher.

## Как враги работают на геймплей
- Каждый враг — «вопрос», на который нужно ответить конкретным приёмом: Idol снимается ближним боем, Stalker отменяет лечение, Power требует парирования.
- **Спавн:** враги выходят из порталов на аренах, закрытых до зачистки.
- **Enrage:** некоторые впадают в ярость (красная аура), например при смерти союзника.
- Враги рядом с Malicious Face/Mindflayer задают приоритеты целей.
