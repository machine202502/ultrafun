# 02. Геймплей

## Главная идея

В ULTRAKILL **не прячутся за укрытиями**. Здоровье восстанавливается только кровью врагов, поэтому игру строят на агрессии, ближнем бою и постоянном движении. Чем ты ближе и наглее, тем дольше живёшь.

## Движение

| Действие | Описание |
|---|---|
| **Бег** | Высокая базовая скорость, без кнопки спринта |
| **Слайд** | Скольжение с сохранением скорости. Из слайда можно прыгнуть дальше обычного |
| **Дэш (уклонение)** | Короткий рывок с неуязвимостью. Расходует стамину: 3 деления, которые восстанавливаются |
| **Прыжок от стены** | До 3 подряд, сбрасываются при касании земли |
| **Слэм (ground slam)** | Резкое падение вниз из воздуха, создаёт ударную волну |
| **Slam storage / slam jump** | Продвинутые техники: энергия слэма превращается в высокий прыжок |
| **Rocket ride** | Можно встать на свою ракету и лететь на ней (с ракетницей Freezeframe) |
| **Whiplash** | Крюк-кошка: притягивает к себе лёгких врагов, а тебя к тяжёлым |

Комбинация слайд → прыжок → дэш → стена даёт огромную скорость и контроль в воздухе.

## Здоровье и кровь

- У V1 100 HP, аптечек почти нет.
- **Лечение кровью:** когда враг погибает рядом, брызги крови восстанавливают здоровье. Чем ближе стоишь, тем больше лечение.
- **Парирование** (удар рукой Feedbacker в нужный момент) отражает снаряды и тоже лечит.
- **Hard damage:** часть урона на время уменьшает максимум здоровья, который можно восстановить. Это наказывает за серию ошибок.

## Стиль (Style Meter)

Справа на экране работает счётчик стиля, как в DMC. Очки дают за разнообразие и зрелищность:
- смену оружия, убийства в воздухе, рикошеты, парирования;
- особые приёмы: headshot, «limb hit», «ricoshot», «fried», «disrespect» и т.п.

Повторение одного приёма снижает награду, свежие действия её повышают.

**Ранги стиля** (по возрастанию):
`DESTRUCTIVE → CHAOTIC → BRUTAL → ANARCHIC → SUPREME → SSADISTIC → SSSHITSTORM → ULTRAKILL`

Набранные очки (P) тратятся в **Терминалах** на новые варианты оружия.

## Оценка уровня

В конце уровня считаются три показателя:
- **Time** — время прохождения;
- **Kills** — число убийств;
- **Style** — очки стиля.

Каждый оценивается буквой `D, C, B, A, S`. Если во всех трёх стоит S и не было ни одной смерти, ставится ранг **P (Perfect)**. P-ранг на всех уровнях акта открывает **Prime Sanctum** с секретным боссом.

## Сложности

| Название | Суть |
|---|---|
| HARMLESS | Почти без угрозы |
| LENIENT | Облегчённая |
| STANDARD | Задуманная по умолчанию |
| VIOLENT | Сложная, задумана как основная для ветеранов |
| BRUTAL | Очень сложная (добавлена позже) |
| ULTRAKILL MUST DIE | Максимальная, ещё не вышла [не уточнено на 2026] |

## Режимы и активности

- **Кампания:** уровни с секретами, черепами-ключами, рычагами, головоломками.
- **Секретные уровни (X-S):** пародии на другие жанры (рыбалка, «Crash Bandicoot», визуальная новелла, текстовая игра и т.д.).
- **The Cyber Grind:** бесконечные волны на меняющейся арене, таблицы рекордов.
- **Sandbox:** песочница, где можно ставить врагов и объекты.
- **Испытания уровней:** у каждого уровня есть особое условие, например «пройти, не прыгая».
- **Developer Museum:** музей разработчиков с комментариями и артефактами.
- **Encore-уровни (X-E):** переосмысленные версии слоёв с новыми темами (добавлены в 2025).

## Прочие детали

- **Чекпоинты** с мгновенным рестартом, смерть стоит дёшево.
- **Терминалы:** магазин оружия и бестиарий с лором врагов.
- Есть кастомизация: цвета оружия, «пиксельность», цветовая палитра и т.п.
