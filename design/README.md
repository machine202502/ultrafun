# design/

Видение игры: мир, персонажи, механики, уровни, стиль. Здесь описано, **какой** должна быть игра. Как это реализовать в коде — в [specs/](../specs/README.md).

Всё здесь — живой черновик. Идеи меняются, это нормально.

## Пометки

- **[решено]** — принято, можно опираться.
- **[черновик]** — направление выбрано, детали могут поменяться.
- **[идея]** — вариант на обсуждение, не опираться.

## Название и язык [решено]

- Название игры — **1681**. `ultrafun` остаётся внутренним рабочим именем репозитория и крейта.
- Язык — английский и русский. **Сначала английский**, русский добавляется позже. Все тексты игры с первого дня лежат в файлах данных, а не в коде (см. [specs/architecture.md](../specs/architecture.md#тексты-и-языки)).

## Главное в двух строках

Ты — бракованное изделие, сошедшее с конвейера огромного подземного завода, который давно работает без людей. Пробивайся вниз, через цеха и трубы, сквозь толпы болванчиков, которых завод производит без остановки.

## Как связано со specs

Когда идея из `design/` идёт в работу, по ней пишется технический спек в `specs/features/` с конкретными числами и критериями готовности. Агент реализует спек, а не дизайн-документ напрямую.
