# Как устроена картинка

## Коротко

Игра рисует сцену в **маленькую картинку** (по умолчанию 480 строк) и растягивает её на окно **без сглаживания**. Отсюда крупные чёткие пиксели, как в старых 3D-играх. Поверх в полном разрешении окна рисуется интерфейс: прицел, здоровье, субтитры, панели F1 и F3. Поэтому текст всегда читается.

Внешний вид поверхностей задают PNG-атласы, UV материалов, освещение, яркость граней и насыщенность. Модели оружия/рук и Болванки — GLB с локальными transforms. Оружие рисуется отдельным проходом после мира, до увеличения изображения, без тумана и depth мира. Подробнее — [combat-and-models.md](combat-and-models.md) и [lighting.md](lighting.md).

## Настройки

Файл `assets/data/settings_default.ron`. Изменения подхватываются на лету, перезапускать игру не нужно.

| Параметр | Сейчас | Что делает |
|---|---|---|
| `internal_height` | `Some(480)` | Высота маленькой картинки в пикселях. Меньше — крупнее пиксели: 240 даёт очень грубую картинку, 720 — почти современную. `None` рисует в полном разрешении окна |
| `vertex_snap` | `false` | **Дрожание вершин** в духе PS1: углы стен «прыгают» по пикселям при движении. Выключено, потому что ломает пиксельные панели на стенах (ниже — почему) |
| `dither` | `false` | Ограничение числа оттенков с **дизерингом**: недостающие оттенки изображаются узором из точек |
| `color_bits` | — | Сколько бит на канал цвета при включённом `dither`: 5 — как на PS1 (32 оттенка), 6 — мягче, 7 — едва заметно, 8 — без ограничения |
| `horizontal_fov_degrees` | 105 | Угол обзора по горизонтали |

## Ретро-эффекты

- **Крупные пиксели** — всегда, пока задан `internal_height`.
- **Дрожание вершин.** На PS1 видеочип не умел считать положение точки на экране точнее пикселя, и при движении геометрия дрожала. Мы повторяем это округлением. С пиксельными панелями эффект плохо уживается: у нас стены и пол — огромные треугольники до 50 м, и дальняя вершина при округлении на полпикселя сдвигается в мире на сантиметры. Узор считается по исходным координатам, поэтому при движении камеры он съезжает внутри стены. На PS1 это прятали, нарезая полы на мелкие треугольники. Если захочется вернуть дрожание, большие грани придётся резать на куски примерно по метру.
- **Ограничение цветов с дизерингом** — выключено. Было полезно, пока поверхности были гладкими; на пиксельных панелях даёт лишний шум.

## Режим скриншотов

`cargo run --release -- --screenshots` снимает каждый режим освещения с точек из `tools/screenshots.ron` и закрывается; снимки — в `target/screenshots`. Подробнее — в [lighting.md](lighting.md#режим-скриншотов).

# Под капотом

## Кадр по шагам

1. **Карты теней** — только если сменился уровень или настройки теней ([lighting.md](lighting.md#карты-теней)).
2. **Сцена в маленькую картинку.** Размер: высота = `internal_height` (не больше высоты окна), ширина = `ширина окна / высота окна × internal_height`, с округлением. Окно 1920×1080 при 480 → 853×480. Здесь считаются свет, узоры, туман, дизеринг.
3. **Растягивание на окно** с выборкой «ближайший пиксель» (без размытия): каждый пиксель маленькой картинки становится квадратом из нескольких пикселей окна.
4. **Интерфейс** поверх, в полном разрешении (библиотека egui).

## Дрожание вершин: формула

Для каждой вершины после проекции на экран:

```
экранная позиция = позиция / w                     (от −1 до 1)
округлённая = round(экранная × полуразмер картинки) / полуразмер картинки
```

Полуразмер картинки — половина ширины и высоты маленькой картинки в пикселях. Затем позиция умножается обратно на `w`. Вершины за камерой не трогаются. Округление ограничено половиной пикселя, но в мире это тем больше, чем дальше вершина.

## Дизеринг: формула

Если `dither` включён, число уровней на канал = `2^color_bits − 1` (5 бит → 31, 7 бит → 127). Для каждого пикселя берётся порог из матрицы Байера 4×4 по его координатам:

```
порог = (число из матрицы + 0,5) / 16
цвет = floor(цвет × уровни + порог) / уровни
```

Матрица раскладывает пороги так, что соседние пиксели округляются по-разному, и плавный переход превращается в равномерный узор из точек вместо резких ступенек.
