# Remote debug: подключение агента к игре

Позволяет агенту подключиться к **работающей** игре человека и работать с ней, не перезапуская: смотреть состояние, делать скриншоты с камеры игрока, подсказывать, куда смотрит человек, управлять и править данные на лету. Игра при этом запускается как обычно; выключить её через протокол нельзя.

## Как включить

Игра запускается с флагом:

```
cargo run -- --remote-debug
```

Без флага сервера нет вообще — на обычной игре это ни на что не влияет. Сервер слушает только `127.0.0.1:4852` (тот же компьютер, наружу наружу не торчит), подключение — одно.

Агент (или человек для проверки) общается пробником:

```
cargo run --example remote_probe -- State
cargo run --example remote_probe -- "Screenshot(path: Some(\"target/shot.png\"))"
```

Пробник отправляет одну команду и печатает ответ (ждёт до 5 секунд).

## Команды

Команда — одна строка в формате RON. Ответ приходит строкой обратно.

| Команда | Что делает | Ответ |
|---|---|---|
| `State` | Позиция, камера, здоровье, время; выбранное оружие, зарядка, beam, снаряды и враги | RON со состоянием |
| `Screenshot(path: Some("..."))` | Снимок кадра с камеры игрока; без `path` — `target/remote_debug.png` | путь или ошибка |
| `LookDelta(dx: 0.05, dy: -0.02)` | Повернуть камеру (радианы) | — |
| `Pointer(x: 640.0, y: 360.0)` | Показать на экране **виртуальный указатель** агента (голубой прицел) | — |
| `Press(action: Jump)` / `Release(action: ...)` | Действия: `Jump`, `Dash`, `Slide`, `Fire`, `AltFire`, `Weapon1`, `Weapon2`, `Weapon3`, `Respawn` | — |
| `MoveInput(x: 0.0, y: 1.0)` | Держать движение (x — вбок, y — вперёд) | — |
| `Reload` | Перечитать изменённые файлы данных (свет, баланс, уровень) | `data reloaded` |
| `SetLevel(name: "foundry")` | Загрузить уровень | `level set to ...` |

## Приоритет ввода

Действия агента **складываются** с вводом игрока: если человек жмёт своё — его ввод главный (движение игрока перебивает `MoveInput`, кнопки объединяются). Виртуальный указатель — только визуальный, он не кликает вместо игрока.

## Сценарий «вот здесь сломано»

1. Человек наводит камеру на проблему и говорит, на что смотреть.
2. Агент: `State` → берёт `eye` и `look_direction`, кидает луч в геометрию уровня — получается точка и конкретный объект.
3. Агент: `Screenshot` → видит то же, что человек.
4. Агент правит файл, затем `Reload` — правка подхватывается без перезапуска.

## Под капотом

- Модуль `src/remote_debug.rs`: TCP-сервер (неблокирующий, опрос раз в кадр в `app/remote.rs`), протокол — построчный RON (`serde`, без новых зависимостей). Одно соединение; при отключении ввод агента сбрасывается.
- Скриншот — тот же путь, что режим автоскриншотов: `renderer.capture()` после кадра, PNG через `image`.
- Команды `Reload`/`SetLevel` переиспользуют живую перезагрузку данных (`app/reload.rs`).
- Намеренно **нет** команд: выйти из игры, закрыть окно, писать произвольные файлы. Только localhost и только с флагом.
