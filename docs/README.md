# Документы для людей

Здесь объяснения на человеческом языке: как устроены части игры и как с ними работать. Без кода и без жаргона, насколько это возможно.

Технические документы для агентов лежат в [specs/](../specs/README.md), видение игры — в [design/](../design/README.md).

Каждый документ устроен одинаково: сначала обзор «как это работает», затем раздел **«Под капотом»** — порядок действий, формулы, состояния и числа, чтобы понять устройство без чтения кода. Агенты обязаны обновлять эти документы, когда меняют соответствующие системы ([правило](../specs/workflow.md#5-обновить-документы)).

| Документ | О чём |
|---|---|
| [game-flow.md](game-flow.md) | Как идёт уровень: управление, арены, выход и отчёт, Диспетчер, тексты, звуки, что меняется на лету |
| [physics.md](physics.md) | Как устроена физика: движение игрока, столкновения, ступеньки, враги, стрельба, детали-лечилки, арены |
| [picture.md](picture.md) | Как устроена картинка: маленькое разрешение и крупные пиксели, дрожание вершин, дизеринг |
| [lighting.md](lighting.md) | Как устроены свет и вид поверхностей: режимы (основной — `arcade`), пиксельные панели, грани, тени, отражённый свет, панель F3, режим скриншотов |
| [blender-levels.md](blender-levels.md) | Как самому менять и строить уровни в Blender — пошаговая инструкция |
| [level-scripting.md](level-scripting.md) | Механизмы уровня: расплав, паровые плиты, ленты, прессы, пневмопочта — как их ставить и что они делают с игроком |
| [combat-and-models.md](combat-and-models.md) | Как устроены модели, анимация, арсенал и боевой звук |
| [remote-debug.md](remote-debug.md) | Как агент подключается к работающей игре: состояние, скриншоты с камеры игрока, управление, правка на лету |
