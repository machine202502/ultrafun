# Документы для людей

Здесь объяснения на человеческом языке: как устроены части игры и как с ними работать. Без кода и без жаргона, насколько это возможно.

Технические документы для агентов лежат в [specs/](../specs/README.md), видение игры — в [design/](../design/README.md).

Каждый документ устроен одинаково: сначала обзор «как это работает», затем раздел **«Под капотом»** — порядок действий, формулы, состояния и числа, чтобы понять устройство без чтения кода. Агенты обязаны обновлять эти документы, когда меняют соответствующие системы ([правило](../specs/workflow.md#5-обновить-документы)).

| Документ | О чём |
|---|---|
| [physics.md](physics.md) | Как устроена физика: движение игрока, столкновения со стенами, ступеньки, враги |
| [lighting.md](lighting.md) | Как устроен свет: лампы, вспышки, «пиксельный» свет, как подкрутить яркость |
| [blender-levels.md](blender-levels.md) | Как самому менять и строить уровни в Blender — пошаговая инструкция |
