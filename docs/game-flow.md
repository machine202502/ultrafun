# Как идёт уровень: от старта до отчёта

## Коротко

1. Уровень начинается, игрок стоит в точке старта. Диспетчер объявляет, что изделие признано бракованным.
2. Игрок идёт по уровню, встречает Болванок и **арены** — залы, которые запираются, пока бой не закончен.
3. Когда все арены пройдены, работает **выход** (у «Утилизации» — площадка пневмопочты). Игрок встаёт в него — игра замирает и показывает **отчёт смены**: время и сколько Болванок уничтожено.
4. Погиб — через 1,5 секунды уровень начинается заново. `R` — начать заново в любой момент.

Голос завода — **Диспетчер**: субтитр внизу экрана на ключевых событиях. **Звуки** привязаны к событиям игры.

Как устроены движение, враги, стрельба, детали-лечилки и арены — в [physics.md](physics.md). Как строить уровни — в [blender-levels.md](blender-levels.md). Механизмы уровня — расплав, ленты, прессы, пневмопочта — в [level-scripting.md](level-scripting.md).

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | Ходьба |
| `Пробел` | Прыжок; у стены в воздухе — прыжок от стены |
| `Левый Shift` | Рывок |
| `Левый Ctrl` | Скольжение на земле, слэм (удар вниз) в воздухе |
| Левая кнопка мыши | Основная атака; первый щелчок захватывает мышь |
| Правая кнопка мыши | Альтернативная атака; резак заряжается удержанием и стреляет отпусканием |
| `1`, `2`, `3` / колесо | Монтажный пистолет, пескоструй, плазменный резак |
| `R` | Начать уровень заново |
| `Esc` | Отпустить мышь |
| `F1` | Отладочная панель |
| `F2` | Следующий уровень по кругу: Утилизация → Литейная → Охлаждение → Контур допуска → тестовая комната |
| `F3` | Лаборатория света ([lighting.md](lighting.md)) |
| `F11` | Полный экран |

Клавиши движения, прыжка, рывка, скольжения и рестарта переназначаются в `keys` в `assets/data/settings_default.ron`.

## Диспетчер

| Когда | Что говорит (ключ текста) |
|---|---|
| Старт и рестарт уровня | `dispatcher.reject_announced` |
| Арена началась | `dispatcher.arena_started` |
| Арена пройдена | `dispatcher.arena_cleared` |
| Игрок погиб | `dispatcher.player_died` |
| Уровень пройден | `dispatcher.level_complete` |

Перед репликой щёлкает радио. Реплика висит 4 секунды; новая сразу заменяет старую.

## Тексты

Весь текст, который видит игрок, лежит в `assets/text/en.ron`: пары «ключ → строка». Язык выбирается в `language` в настройках (пока есть только английский). Если ключа в файле нет, на экране показывается сам ключ — так пропуск сразу виден. В коде текстов для игрока нет.

Тексты читаются при запуске; после правки `en.ron` игру нужно перезапустить.

## Звуки

Пока это заглушки, синтезированные кодом: `cargo run --example placeholder_sounds` пересоздаёт их в `assets/audio/`.

| Событие | Звук |
|---|---|
| Выстрел | `shot` |
| Попадание в стену | `impact` (тише с расстоянием) |
| Попадание по Болванке / её смерть | `enemy_hit` / `enemy_killed` (смерть тише с расстоянием) |
| Подобрана деталь | `part_collected` |
| Игрока ударили | `player_damaged` |
| Прыжок, рывок, слэм | `jump`, `dash`, `slam` |
| Арена закрылась | `door` |
| Арена пройдена, уровень пройден | `chime` |
| Реплика Диспетчера | `radio` |

Общая громкость — `master_volume_db` в настройках (сейчас −6 дБ). Нет звукового устройства — игра работает без звука.

## Музыка

Две процедурные петли по 32 секунды: `music_calm.wav` (гул цеха, шипение пара, капель) и `music_battle.wav` (пульс, бас, хэты) — генерируются `cargo run --example placeholder_music`. Спокойная играет, пока идёшь по уровню; при закрытии арены включается боевая, после победы — снова спокойная. Музыка закольцована и звучит тише эффектов (−8 дБ).

## Что меняется на лету

Игра следит за папками `assets/data`, `assets/levels`, `assets/textures` и `assets/models`. Сохранили файл — изменения применились без перезапуска; ошибка атласа/модели сохраняет последний рабочий набор. Текстуры и модели не сбрасывают игровой прогресс.

| Файл | Что |
|---|---|
| `settings_default.ron` | Чувствительность мыши, угол обзора, картинка ([picture.md](picture.md)), клавиши, громкость |
| `movement.ron` | Скорости, прыжки, рывок, скольжение |
| `weapons.ron` | Урон, скорострельность, дальность |
| `health.ron` | Здоровье, задержка рестарта, детали-лечилки |
| `grunt.ron` | Болванка: здоровье, скорость, удар |
| `lighting.ron` | Режимы освещения |
| `assets/levels/<уровень>.glb` и `.ron` | Сам уровень (уровень при этом начинается заново) |

Ошибка в файле не роняет игру: в лог пишется, что не так, и остаются старые значения.

# Под капотом

## Как события доходят до звука и субтитров

Логика игры (крейт `game`) ничего не знает о звуке, картинке и тексте. За каждый шаг она складывает в список **события**: «выстрел», «Болванка убита», «арена началась» и т. д. Приложение после шага разбирает список:

1. **Звук** — каждому событию свой файл. Громкость = общая + затухание.
2. **Диспетчер** — если событию соответствует реплика, запоминает её ключ на 4 секунды и включает радио-щелчок.
3. **Эффекты** — следы выстрелов, вспышки, свечение деталей.
4. **Интерфейс** — субтитр берёт строку по ключу из `en.ron`.

## Затухание звука

Звуки с точкой в мире (попадание в стену, смерть Болванки) тише с расстоянием до игрока:

```
затухание = max(−расстояние / 2, −30) дБ
```

То есть −1 дБ на каждые 2 метра, но не тише −30 дБ. Звуки самого игрока (выстрел, прыжок) не затухают. Влево-вправо звук пока не разводится.

## Выход и отчёт

Каждый шаг: если у уровня есть выход, **все** арены пройдены и центр игрока внутри зоны выхода — запоминаются время и число убитых, событие «уровень пройден». После этого логика больше не идёт, игрок не двигается, на экране отчёт:

- время = число шагов × 1/120 с, в формате мм:сс.д;
- уничтожено Болванок — все убитые за попытку, включая арены.

`R` сбрасывает и время, и счётчик. Если у уровня есть следующий уровень (`next_level` в его `.ron`), в отчёте есть строка «Press Enter for the next shift»: `Enter` загружает следующий уровень, `R` — как раньше, начинает текущий заново.

## Смерть и рестарт

Здоровье дошло до нуля → событие «игрок погиб», запускается отсчёт `restart_delay_seconds` (1,5 с, `health.ron`). Пока он идёт, логика стоит.

Дальше — два разных случая:

- **Контрольная точка пройдена** — игрок появляется на последней точке с полным здоровьем и полным запасом рывков. Всё, что он сделал, остаётся: открытые двери, сломанные полы, ключи, выключенный расплав, сработавшие триггеры, убитые Болванки. Сбрасывается только бой: активная арена возвращается в ожидание, её Болванки и станок убираются, её двери открываются. Время уровня идёт дальше.
- **Контрольной точки нет** — полный рестарт: игрок в точке старта, мишени и Болванки на исходных местах, арены ждут, детали убраны, время и счётчик с нуля.

`R` в любом случае — полный рестарт, включая контрольные точки, ключи и триггеры. Подробно про точки и триггеры — [level-scripting.md](level-scripting.md).

## Выбраться, если застрял

Клавиша **R** (`respawn` в `assets/data/settings_default.ron`) возвращает игрока на **последний чекпоинт**, а не перезапускает уровень: прогресс (ключи, открытые двери, сломанные панели) сохраняется, активные арены сбрасываются в ожидание. Если чекпоинтов ещё не было, происходит полный перезапуск уровня — как раньше.

Чекпоинты стоят в начале маршрута: приёмник, сортировочная, мостки, тоннели, шахта, склад форм, прессы, литейный зал, разливочная, переправа, резервуар, крановый пролёт. Поэтому падение в любую яму — это максимум несколько метров отката, а не потеря забега.

## Чит-режим

**F4** (`cheats` в `assets/data/settings_default.ron`) включает и выключает чит-режим. Пока он включён:

- игрок **летает**: движение по взгляду (W/S — вперёд/назад, включая вертикаль, A/D — в сторону), скорость 24 м/с, гравитации нет;
- **noclip**: столкновения игнорируются, можно проходить сквозь стены и пол;
- при включении и выключении скорость обнуляется, состояние сбрасывается в обычное;
- падение за карту в чит-режиме не убивает;
- в левом верхнем углу горит «FLY + NOCLIP».

Выключил — игрок снова падает, сталкивается со стенами и умирает от лавы/падения как обычно.

## Меню запуска

При старте без аргументов игра показывает меню и не делает шагов логики: тёмный фон, крупное название шрифтом Russo One и **плитки уровней**. Игра на это время на паузе, курсор свободен, HUD не рисуется.

- **Плитки уровней** — по одной на каждый уровень из `levels::SWITCHABLE_LEVELS`: снимок уровня (из `assets/levels/previews/<имя>.png`), подпись, рамка выбранного. Клик — загрузить уровень, меню закрывается, мышь захватывается. Стрелки/Enter — то же с клавиатуры. Нет файла превью — тёмная плитка с буквой.
- **SETTINGS** — кнопка-заглушка, ничего не делает.
- **EXIT** — закрывает игру.

Превью перегенерируются командой `cargo run -- --make-previews` (сама снимает каждый уровень со стартовой точки и выходит; превью — кадр сцены без HUD и меню). Подписи — в `assets/text/en.ron` (`menu.title`, `menu.settings`, `menu.exit`, `level.*`).

**Шрифты:** заголовки — Russo One, терминальный текст — PT Mono (оба с кириллицей, OFL, в `assets/fonts/`, запись в `assets/CREDITS.md`); ставятся в egui при старте, файл шрифта отсутствует — используются стандартные с предупреждением в логе. Код меню — `src/menu.rs`, отрисовка в `src/overlay.rs`. В режимах скриншотов и превью меню принудительно выключено.

## Пауза

**Escape** в игре останавливает симуляцию и показывает маленькое меню поверх сцены (сцена остаётся видна):

- **RESUME** — вернуться в игру (мышь снова захватывается);
- **MAIN MENU** — выйти в главное меню (сцена за ним не рисуется).

Повторный Escape закрывает паузу и продолжает игру. Пока пауза открыта, время не копится и шаги симуляции не выполняются. Подписи — `pause.title`, `pause.resume`, `pause.main_menu` в `assets/text/en.ron`, код — `PauseMenu` в `src/menu.rs`.
