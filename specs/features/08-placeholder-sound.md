# 08. Звуки-заглушки

**Статус:** готово

## Зачем
Без звука стрельба и бой ощущаются пустыми. Настоящих звуков пока нет ([specs/assets.md](../assets.md)), поэтому — синтезированные заглушки, чтобы проверить ощущения и подключить звук к событиям игры.

## Откуда звуки
- Пример `examples/placeholder_sounds.rs` синтезирует звуки кодом (шум, свипы, металлические призвуки) и пишет WAV в `assets/audio/`. Без новых пакетов.
- Это собственная работа проекта, лицензия CC BY-SA 4.0. Запуск: `cargo run --example placeholder_sounds`.
- Формат — WAV 16 бит, моно, 44,1 кГц (для заглушек; финальные звуки — OGG, по [assets.md](../assets.md)).

## Звуки и события
| Событие | Звук |
|---|---|
| `ShotFired` | `shot` — щелчок с низким ударом |
| `ShotImpact` | `impact` — короткий тик |
| `EnemyHit` | `enemy_hit` — глухой удар |
| `EnemyKilled` | `enemy_killed` — хруст с падающим тоном |
| `PartCollected` | `part_collected` — восходящий блип |
| `PlayerDamaged` | `player_damaged` — низкий гул |
| `Jumped` | `jump` — короткий блип |
| `Dashed` | `dash` — свист |
| `Slammed` | `slam` — тяжёлый удар |
| `ArenaStarted` | `door` — металлический лязг |
| `ArenaCleared`, `LevelCompleted` | `chime` — восходящий аккорд |
| Реплика Диспетчера | `radio` — радио-щелчок перед субтитром |

- Громкость удалённых событий (попадание по стене, смерть врага) падает с расстоянием до игрока: −1 дБ на каждые 2 м, не тише −30 дБ.
- Общая громкость — `master_volume_db` в `settings_default.ron`.
- Нет звукового устройства — игра работает без звука и пишет предупреждение в лог.

## Не входит
- Музыка и её спокойная и боевая версии.
- Объёмный звук (позиционирование влево и вправо).
- Озвучка Диспетчера.

## Критерии готовности
- [x] Генератор детерминирован: повторный запуск даёт те же файлы.
- [x] Тест: заголовок WAV корректен (размеры совпадают с числом сэмплов).
- [x] Тест в `game`: прыжок и рывок порождают события `Jumped` и `Dashed`.
- [x] **Человек поиграл со звуком** и подтвердил, что заглушки не раздражают и помогают.
