# 03. Монтажный пистолет и мишени

**Статус:** готово

## Зачем
Первое оружие ([design/weapons.md](../../design/weapons.md)) и то, во что можно стрелять, пока нет врагов. Проверяем, что стрельба ощущается хорошо в движении.

Все числа — в `assets/data/weapons.ron`.

## Выстрел
| Параметр | Значение |
|---|---|
| Тип | Мгновенный луч (hitscan) из глаз по направлению взгляда |
| Урон | 1 |
| Перезарядка между выстрелами | 0,3 с |
| Дальность | 500 м |
| Кнопка | Левая кнопка мыши, при удержании стреляет с темпом перезарядки |

- Луч останавливается о первую преграду: стену уровня или мишень.
- Клик, которым захватывается мышь, не стреляет.

## Мишени
- Задаются в данных уровня (`targets` в `test_room.ron`): центр, размер, здоровье.
- Не мешают движению игрока, только принимают выстрелы.
- Цвет темнеет по мере потери здоровья, при нуле мишень исчезает.
- `R` (возврат на старт) восстанавливает все мишени.

## Обратная связь
- Прицел — точка в центре экрана. Временно рисуется через `egui`, до отдельного спека HUD.
- След выстрела — тонкая светлая линия от ствола (справа снизу от взгляда) до точки попадания, держится 0,1 с. Выстрел остаётся мгновенным лучом: так задумано, как у револьвера в ULTRAKILL. Летящим снарядом будет альтернативная атака.
- Отметка попадания — маленький кубик в точке попадания по стене, исчезает через 2 с.
- События: `ShotFired { origin, end }`, `ShotImpact { position, normal }`, `TargetHit { id }`, `TargetDestroyed { id, position }`.

## Развитие

Альтернативная атака, модель и звук реализованы в боевом проходе: [15-laboratory-and-combat.md](15-laboratory-and-combat.md). `ShotFired` дополнительно несёт `weapon` и `mode`. Приведённые выше primary-числа сохранены; прежние критерии человеческой оценки относятся только к старой версии пистолета, не подтверждают качество нового арсенала.

## Исторические границы первого этапа
- Альтернативная атака (раскалённая заклёпка) — со спеком врагов: без врагов её не проверить.
- Модель оружия в руках, отдача, звук, вспышка выстрела.

## Критерии готовности
- [x] Тесты в `game`: урон по мишени, уничтожение, стена закрывает мишень, темп стрельбы ограничен перезарядкой, восстановление мишеней по `R`.
- [x] Числа в `weapons.ron` меняются без перекомпиляции.
- [x] **Человек пострелял** в движении и подтвердил, что ощущается нормально.
