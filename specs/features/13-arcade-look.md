# 13. Картинка в духе ULTRAKILL

**Статус:** первая версия, ждёт оценки человеком

## Зачем
Реалистичный свет не даёт нужного вида. У ULTRAKILL картинка светлая и насыщенная, везде пиксельные текстуры, форма читается за счёт разной яркости граней, тени неглубокие.

## Поведение
- Процедурная пиксельная текстура в шейдере по мировым координатам: панели 16×16 пикселей со швом и фаской, шум по пикселям и панелям. Плотность — `texture_pixels_per_meter`, сила — `texture_strength`.
- Затенение граней по нормали (`face_shading`): верх 1, низ 0,5, бока по X 0,8, по Z 0,65.
- Насыщенность итогового цвета (`saturation`).
- Режим `arcade` в `lighting.ron`, активный: без тонмаппинга, сильная подсветка, слабые тени, без отражённого света.

## Не входит
- Настоящие текстуры из файлов и разные узоры для разных материалов.
- Смена палитры уровня «Утилизация».

## Критерии готовности
- [x] Скриншоты всех кадров в режиме `arcade` без артефактов.
- [ ] Человек сравнил с ULTRAKILL и подтвердил направление.
