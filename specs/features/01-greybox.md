# 01. Серая коробка: окно, камера, тестовая комната

**Статус:** готово

## Зачем
Минимальная оболочка, чтобы человек мог запустить игру, побегать и настроить движение ([02-movement.md](02-movement.md)). Без неё движение нельзя проверить.

## Поведение
- Окно 1280×720, можно менять размер и переключать полноэкранный режим (`F11`).
- Камера от первого лица. Мышь захватывается при клике в окно, `Esc` её отпускает.
- Поворот мышью: рысканье без ограничений, наклон ограничен ±89°. Чувствительность и поле зрения (по умолчанию 105° по горизонтали) — в `assets/data/settings_default.ron`.
- Тестовая комната — набор коробок из `assets/data/test_room.ron`: пол, стены разной высоты, пандус 30°, пандус 50° (по нему нельзя забраться), ступеньки по 0,4 м, платформа на высоте 3 м, высокая стена 15 м для прыжков от стен, коридор шириной 5 м, узкий лаз высотой 1,4 м (проходится только скольжением).
- Отрисовка: коробки однотонными цветами с простым направленным светом и туманом по расстоянию. Без текстур и эффектов PS1, они идут отдельным спеком.
- Отладочная панель (`F1`, `egui`): FPS, шагов логики за кадр, позиция, углы обзора. Скорость, стамина, состояние движения и счётчик прыжков от стен добавляются вместе с [02-movement.md](02-movement.md).
- `assets/data/*.ron` перезагружаются на лету при сохранении файла.
- `R` — вернуть игрока в точку старта.
- Логика обновляется с фиксированным шагом 120 Гц, отрисовка интерполирует ([architecture.md](../architecture.md#главный-цикл)).

## Не входит
- Текстуры, модели, эффекты PS1, звук, HUD, меню.
- Загрузка уровней из Blender.
- Геймпад.

## Критерии готовности
- [x] `cargo run` открывает окно с тестовой комнатой на Windows.
- [x] Можно осмотреться мышью, мышь захватывается и отпускается.
- [x] Правка файлов данных подхватывается без перезапуска; ошибка в файле пишется в лог и не роняет игру.
- [x] Логика игры в крейте `game`, окно и рендер — в `ultrafun`.

## Открытые вопросы
- Проверить на Linux — нужен человек с Linux-машиной или CI.
