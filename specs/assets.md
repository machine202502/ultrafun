# Ассеты

Модели, текстуры, звуки, музыка, уровни: где брать, как делать, как хранить.

## Лицензии

Весь контент проекта — **CC BY-SA 4.0** ([LICENSE-ASSETS](../LICENSE-ASSETS)). Сторонний ассет можно взять, только если его лицензия совместима.

| Можно | Нельзя |
|---|---|
| CC0 (общественное достояние) | CC BY-NC (запрет коммерции) |
| CC BY 3.0/4.0 | CC BY-ND (запрет изменений) |
| CC BY-SA 3.0/4.0 | «Royalty-free» с запретом распространять исходные файлы (Sonniss GDC, Mixamo, Unity Asset Store, большинство паков itch.io со своей лицензией) |
| Своя работа участника проекта | Всё из других игр, включая ULTRAKILL |
| | Ассеты без явно указанной лицензии |

Причина запрета «royalty-free»: репозиторий открытый, значит, мы распространяем сами файлы, а такие лицензии это запрещают.

**Каждый сторонний ассет** записывается в [assets/CREDITS.md](../assets/CREDITS.md): файл, автор, источник, лицензия. Без записи ассет в репозиторий не попадает.

## Ассеты как код

Простые модели (ящики, колонны, стены, детали арен, оружие из примитивов) агенты делают **скриптами Blender на Python**:
- скрипт лежит в `tools/blender/<имя>.py`;
- запускается без интерфейса: `blender --background --python tools/blender/<имя>.py`;
- результат экспортируется в `assets/models/<имя>.glb`.

Так модель воспроизводима, агент может её поправить, а исходник — текст, который видно в diff.

Blender MCP допустим для интерактивной работы, но итоговый результат фиксируется скриптом или `.blend`-файлом в `art/`.

## Персонажи и враги

- Враги по возможности **сегментные**: жёсткие части без скиннинга (как роботы и куклы эпохи PS1). Их анимирует код, отдельные анимационные файлы не нужны.
- Если нужен скелет и скиннинг — Rigify в Blender или CC0-анимации Quaternius. Mixamo нельзя (см. лицензии).
- Генерация 3D нейросетями допустима как основа: результат обязательно упрощается до бюджета полигонов и проверяется на лицензию сервиса (вывод должен разрешать коммерческое использование и перелицензирование под CC BY-SA).

## Уровни

- Уровни делаются в Blender и экспортируются в `assets/levels/<имя>.glb`.
- Игровые объекты (точка старта, спавны врагов, триггеры, двери) — объекты сцены с договорёнными именами. Соглашение по именам описывается в спеке фичи загрузки уровней.

## Где что хранится

```
art/      — исходники: .blend, многослойные текстуры, проекты звука
assets/   — то, что грузит игра: .glb, .png, .ogg, .ron
tools/    — скрипты генерации ассетов
```

## Бюджеты в стиле PS1

Значения по умолчанию. Эффекты рендера включаются и выключаются в настройках игры.

| Что | Бюджет |
|---|---|
| Внутреннее разрешение рендера | высота 480 (на 16:9 — 853×480), растягивается на окно без сглаживания. Меняется в настройках, вплоть до родного |
| Текстура мелкого объекта | 32×32 |
| Текстура обычного объекта и стен | 64×64 |
| Текстура крупной поверхности, максимум | 128×128 |
| Текстура оружия в руках | до 256×256 |
| Модель врага | 300–800 треугольников |
| Модель оружия в руках | до 1500 треугольников |
| Предмет обстановки | 50–300 треугольников |

**Эффекты рендера:**
- текстуры без фильтрации и мипмапов (чёткие пиксели);
- привязка вершин к сетке внутреннего разрешения (дрожание вершин);
- аффинное искажение текстур (отключаемо);
- пониженная глубина цвета с дизерингом (7 бит на канал по умолчанию, мягче настоящих 5 бит PS1);
- освещение по вершинам, без теней (под врагами — простое тёмное пятно);
- туман по расстоянию в цвет горизонта.
